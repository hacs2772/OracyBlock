# 진짜 휴대폰 점검표 (10분)

시험 서버에서는 확인할 수 없는 것들이에요. 아이폰 하나, 갤럭시 하나로 해 보고, 안 되는 줄만 캡처해서 알려 주세요.
처음 온 사람처럼 보려면 사파리·크롬의 **개인정보 보호 탭(시크릿 창)**에서 oracyblock.com을 열어요.

## 소리

- [ ] 대화를 시작하면 상대 말이 들린다 (이어폰 없이)
- [ ] 소리가 안 나면 말풍선의 재생 버튼을 누르면 들린다
- [ ] 아이폰 옆 무음 스위치를 켠 채로: 일본어 말소리가 나는지, "딸깍" 효과음이 나는지 (둘 중 무엇이 안 나는지 적어 주세요)
- [ ] 내 정보 › 듣기에서 다른 목소리로 바꾸면 바로 바뀐다
- [ ] 복습 화면에서 단어를 누르다가 다른 탭으로 가면 소리가 멈춘다

## 화면

- [ ] 대화 화면: 탑 → 얼굴·말풍선 → 문제 → 보기 5개가 스크롤 없이 한 화면에 보인다
- [ ] 글자가 잘리거나 버튼 밖으로 넘치는 곳이 없다 (가로로 밀리는 화면이 없다)
- [ ] 카카오톡에서 링크를 열었을 때 "다른 브라우저로 열기" 안내가 뜬다

## 홈 화면에 추가 · 알림

- [ ] 아이폰 사파리: 공유 › 홈 화면에 추가 → 아이콘으로 열면 주소창 없이 앱처럼 열린다
- [ ] (아이폰 X 이후, 홈 화면 아이콘으로 열고) 상점·내 정보 맨 아래까지 내렸을 때 마지막 줄이 아래 탭에 가리지 않는다. 아래에서 올라오는 창이 홈 바(맨 아래 줄)에 붙지 않는다
- [ ] 대화를 끝낸 화면의 "알림 받기"를 누르면 바로 "알림이 켜졌어요" 시험 알림이 온다
  - 아이폰은 홈 화면에 추가한 아이콘으로 열었을 때만 돼요
- [ ] 내 정보 › 알림에서 시간을 바꾸고, 끄고 켤 수 있다

## 인터넷이 끊겼을 때

- [ ] 대화 중에 비행기 모드를 켜면 위에 "인터넷이 끊겼어요" 한 줄이 뜬다
- [ ] 비행기 모드인 채로 대화를 끝내고 → 비행기 모드를 끄면 "끊겼을 때 끝낸 대화를 저장했어요"가 뜨고, 홈의 내 탑에 1층이 쌓여 있다
- [ ] 비행기 모드에서 앱을 새로 열어도 하얀 화면이 아니라 홈이 뜬다

## 공유 · 로그인

- [ ] 내 탑 › 공유 카드의 "사진 저장" → 사진첩에 정사각형 그림으로 저장된다
- [ ] 둘러보기로 대화 하나 → 가입하면 그 탑과 브릭이 그대로 남아 있다
- [ ] 로그아웃 → 다시 로그인하면 기록이 그대로다
