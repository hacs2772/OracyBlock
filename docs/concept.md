# OracyBlock 컨셉 (사용자와 정한 것)

> 마지막으로 고친 날: 2026-11-19
> 이 문서는 사용자와 대화하면서 **확정한 내용**만 적어요. 아직 안 정한 것은 맨 아래 "아직 정하지 않은 것"에 따로 둬요.
> 함께 읽을 문서: [`brief.md`](brief.md)(GPT와 정리한 초기 기획), [`eartomouth-handoff.md`](eartomouth-handoff.md)(이전 이름 EarToMouth v1~v5 인수인계)

---

## 1. 한 줄

일본 여행에서 **옆자리 사람의 말을 알아듣고 대답하는** 걸, 브릭을 끼워 쌓는 게임으로 연습해요. 읽기·쓰기는 필요 없어요.

- 메인 슬로건: **Hear it. Say it. No reading required.**
- 서브 슬로건: **Build real conversations, block by block.**
- 한국어: **듣고, 말하고, 읽기 공부는 생략.**

## 2. 그대로 지킬 것 (EarToMouth에서 이어짐)

- 목표 두 가지: ① 다 못 알아들어도 **핵심 단어와 어감으로 뜻을 맞히기** ② 문법이 완벽하지 않아도 **말해서 통하기**
- 해석은 **맞힌 다음에** 보여 줘요. 처음부터 해석을 보여 주지 않아요.
- 상황은 가게 주문보다 **옆자리 대화** 중심 (비행기, 이자카야, 온천, 바 등)
- **0원 운영**: 서버 비용 없이. 음성은 브라우저 기능(무료). 도메인 값만.
- 휴대폰이 기준이에요 (아래 7절)

### 하지 않을 것 (사용자가 직접 거절)

- 듀오링고 같은 것: 위에 X + 진행 막대 + 아래 큰 "계속" 버튼, **단어 타일로 문장 조립**, 연속 기록(스트릭)·주간 체크, 길 따라 이어진 레슨 지도
- AI가 만든 것 같은 화면: 보라색 그라데이션, 이모지 카드, 반짝이(✦✨), em dash(—), 섹션 위 작은 머리말, "1·2·3 단계" 카드 묶음
- 스픽 같은 유료 구조
- 다른 서비스의 이름·캐릭터·그림·문장, 특정 완구 회사의 로고·상표 디자인

## 3. 브릭 컨셉

### 3-1. 구조물: 주고받아야 맞물리는 벽

- 상대가 한 마디 하면 **민트 브릭**, 내가 대답하면 **코랄 브릭**
- 내 브릭은 상대 브릭 위에 **반 칸씩 엇갈려** 걸쳐 올라가요. 주고받아야 구조물이 단단해져요 (Listen → Speak → Connect)
- 대화 하나(3~5턴)를 마치면 맨 위에 **노란 완성 브릭**이 얹혀 작은 구조물이 완성돼요

### 3-2. 상대 말 → 뜻 맞히기: 맞거나, 튕기거나

1. 상대가 말해요. 글자 없이 소리만. 다시 듣기·느리게 듣기.
2. 아래에 **뜻이 적힌 브릭 5개**가 나와요 (5지선다를 브릭으로)
3. 맞는 브릭을 고르면 날아가서 구조물에 **딸깍** 끼워져요
4. 틀린 브릭은 올라가다가 돌기가 안 맞아서 **퉁** 하고 튕겨 나가요. "오답" 글자는 쓰지 않아요
   - 한 번 튕기면: 상대가 느리게 한 번 더 말해 줘요
   - 두 번 튕기면: 맞는 브릭이 살짝 빛나요
5. 맞히면 해석을 보여 줘요: 한글 발음(핵심 단어 강조), 뜻, 말투(반말/존댓말 등)

### 3-3. 내 대답: 딱 맞음 / 어긋남 / 틀림 (세 칸)

| 칸 | 기준 | 브릭 |
|---|---|---|
| **딱 맞음** | 질문에 맞는 내용을 자연스럽게 말함 | 딸깍, 딱 맞게 끼워짐 |
| **어긋남** | 뜻은 통하는데 **외국인 티가 나는 말** | 반 칸쯤 비뚤게 얹힘 (그래도 쌓이고 대화는 이어짐) |
| **틀림** | 질문과 **상관없는 말** | 안 맞아서 튕겨 나감 |

어긋남의 예 (사용자가 든 예):
- 단어 대신 가리키면서 **"이거!"**
- **존댓말 질문에 반말**로 대답: "식사 어땠어요?" → "응, 맛있어"
- **때(시제)가 안 맞음**: "어땠어요?" → "맛있네"
- **숫자·날짜를 서툴게**: "언제 귀국해요?" → "일, 이, 삼 일", "셋일 뒤", "내일 내일 내일"

질문별 예:

| 질문 | 딱 맞음 | 어긋남 | 틀림 |
|---|---|---|---|
| 뭐 마셔요? | 맥주! / 하이볼이에요 | (가리키며) 이거! | 맛있어요 |
| 식사 어땠어요? (존댓말) | 아주 맛있었어요 | 응, 맛있어 | 날씨 좋네요 / 차가 막히네요 |
| 언제 귀국해요? | 3일 뒤 / 12월 10일 / 이번 주 금요일 | 3일을 틀린 읽기로, "일, 이, 삼 일", "내일 내일 내일" | 길이 막히네요 |

### 3-4. 말투 규칙

- **반말 질문 → 반말 대답, 존댓말 대답 둘 다 딱 맞음.** 대신 **"상대가 반말했어요"라고 알려 줘요**
- **존댓말 질문 → 반말 대답은 어긋남**

### 3-5. 어긋났을 때 / 튕겼을 때

- **어긋남:** 브릭이 비뚤게 얹힘 → "통했어요!" → "이렇게 말하면 딱 맞아요"와 함께 자연스러운 대답을 **소리로** 들려줌 → 그 자리에서 다시 말해 딱 맞으면 비뚤어진 브릭이 스르륵 **바로 서요**. 그냥 넘어가도 돼요
- **틀림:** 브릭이 튕겨 나감 → 상대가 "응? 한 번 더?" → 추천 대답을 알려 줌
- **정말 쉬운 질문에서 튕겼을 때:** 추천 대답으로 **"일본어 잘 못해요", "천천히 말해 주세요"** 같은 살리는 말도 알려 줘요 (대사마다 "쉬움" 표시)
  - 살리는 말을 실제로 하면: 브릭은 안 쌓이지만 튕기지도 않고, 상대가 더 천천히·쉽게 다시 물어봐요
- 두 번 튕기면 "대신 들려주기"를 권해요 (EarToMouth v5와 같음). 막혀서 멈추는 일은 없게

### 3-6. 브릭 종류

| 브릭 | 색 | 뜻 |
|---|---|---|
| 상대 브릭 | 민트 `#29B6A5` | 상대가 한 말 (알아들으면 생김) |
| 대답 브릭 | 코랄 `#FF7967` | 내가 한 대답 |
| 질문 브릭 | 노랑 `#FFC857` | 내가 되물은 말. 옆으로 돌기가 하나 더 나와 있어 다음 대화를 이어 붙이는 고리 (asmrBlock 블록의 오른쪽 돌기 오마주) |
| 완성 브릭 | 노랑 | 대화 하나를 마치면 맨 위에 |
| 빠진 돌기 | (브릭에 구멍) | **놓친 단어**. 복습에서 맞히면 돌기가 채워져요 |
| 비뚤어진 브릭 | (기울어짐) | **어긋난 대답**. 다시 말하면 바로 서요 |

### 3-7. 소리·느낌

- 맞음 **딸깍**, 어긋남 **툭**, 튕김 **퉁**. 소리 끄기 가능
- 안드로이드는 짧은 진동도 (아이폰 브라우저는 진동을 지원하지 않음)
- 폰의 "동작 줄이기"가 켜져 있으면 움직임 없이 결과만

## 4. 한 대사의 흐름

1. 상대가 말함 (소리만, 다시·느리게)
2. 뜻 브릭 5개 중 고르기 → 민트 브릭 딸깍 (틀리면 튕김)
3. 해석 공개: 한글 발음·뜻·말투
4. 내 차례: 하고 싶은 말(예: "혼자라고 하기")을 고르면 일본어로 먼저 들려줌 → 마이크로 말하기 → 세 칸 판정 → 코랄 브릭
5. 상대 반응 → 다음 대사

## 5. 홈: 내 여행 판

- 길 지도·잠금 해제 대신 **레고 바닥판 하나**. 이자카야·온천·신칸센 같은 **자리**가 있고, 대화를 마친 곳에는 그때 쌓은 구조물이 서 있어요
- 아무 곳이나 골라서 시작 (잠금 없음)
- 연속 기록(스트릭)·콤보는 하지 않아요

## 6. 복습 = 구조물 고치기

- 놓친 단어(빠진 돌기)를 소리로 듣고 뜻을 맞히면 돌기가 채워져요
- 간격 반복: 1일 → 3일 → 7일 → 14일 → 30일 (EarToMouth v5 그대로)
- 한국어와 소리가 닮은 단어(有名 유-메- ≈ 유명)도 가끔 추천

## 7. 플랫폼

- **웹사이트를 먼저** 만들어요. 하지만 사용자 대부분은 **휴대폰 웹**으로 보거나 **앱을 받아서** 쓸 거예요
  - 모든 화면은 휴대폰 크기가 기준 (아이폰 SE 320px까지 넘치지 않게)
  - 홈 화면에 추가하면 앱처럼 (PWA)
  - 나중에 앱(asmrBlock처럼 Expo/React Native)으로 옮기기 쉬운 구조로
- 무료 정적 호스팅 (Cloudflare Pages 계획)
- 언어: 한국어 화면 + 일본어 학습부터. 영어·중국어는 나중에 언어 팩으로

## 8. asmrBlock 오마주

- **같은 핏줄:** 브릭 만드는 법(진한 테두리·아래 두께·돌기), 블록 모양 버튼, 레고 판 카드, 제목 도현체, "AI 티 안 나게" 규칙
- **반대 분위기:** asmrBlock = 밤(잠)·옆으로 누운 블록·왼쪽→오른쪽 타임라인 / OracyBlock = 낮(여행)·크림 바탕·위로 쌓는 입체 블록

## 9. 아직 정하지 않은 것

- 브릭 모양 시안 A(플라스틱) / B(테두리) / C(말랑) 중 무엇으로 할지
- 대답 차례에 하고 싶은 말을 **빈 브릭 윤곽**으로 미리 보여 줄지, 자유롭게 말하게 할지
- EarToMouth v5의 "들린 단어 고르기"를 뺄지 (제안: 빼고, 뜻을 틀린 대사의 핵심 단어를 "놓친 단어"로)
- 추천 대답의 한글 발음: 처음부터 보일지 / "힌트"를 눌러야 보일지 (제안: 힌트)
- 판정: 처음엔 규칙(대사마다 딱 맞음·어긋남 대답을 미리 적어 둠)으로, 나중에 AI 키를 넣으면 처음 듣는 말도 세 칸으로 나누는 자리를 만들어 둘지
- 다크 모드
- 숫자를 틀리게 읽은 것(예: 3일)을 음성 인식으로 구분할 수 있는지 → 만들 때 실제로 시험
