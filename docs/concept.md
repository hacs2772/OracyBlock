# OracyBlock 컨셉 (사용자와 정한 것)

> 마지막으로 고친 날: 2026-11-19 (시안 6차: 대화마다 브릭 1개·하루 최대 3개, 레벨 추천 방식, 서버 기술·도메인 확정, 웹 첫 화면 새로)
> 이 문서는 사용자와 대화하면서 **확정한 내용**만 적어요. 아직 안 정한 것은 맨 아래 "아직 정하지 않은 것"에 따로 둬요.
> 함께 읽을 문서: [`brief.md`](brief.md)(GPT와 정리한 초기 기획), [`eartomouth-handoff.md`](eartomouth-handoff.md)(이전 이름 EarToMouth v1~v5 인수인계)

## 0. 목표 (꼭 기억하기)

- 목표는 **옆자리 사람과 스몰토크**예요.
- **JLPT 준비도, 완벽한 회화도 아니에요.** 상대가 한 말을 정확히 다 알아듣는 게 목표가 아니에요. 잘하는 사람은 정확하게 할 수도 있지만, 기본은 "통하면 된다"예요.
- **가장 중요한 건 단어예요.** 문법, 존댓말, 어감보다 단어가 먼저예요.
  - 상대 말: 핵심 단어가 들리면 뜻을 맞힐 수 있어요.
  - 내 대답: 핵심 단어 하나만 말해도 통해요. "와따시와 칸코쿠진데스"가 가장 좋지만 "칸코쿠진", "칸코쿠"만 말해도 **딱 맞음**이에요. "뭐 마셔요?"에 "비-루", "비-루데스"도 딱 맞음이에요.
  - **맞혀도, 틀려도, 복습할 때도 단어를 크게 보여 주고 들려줘요.**

## 1. 한 줄

일본 여행에서 **옆자리 사람의 말을 알아듣고 대답하는** 걸, 브릭을 끼워 쌓는 게임으로 연습해요. 읽기·쓰기 공부는 필요 없어요.

- 메인 슬로건: **Hear it. Say it. No reading required.**
- 서브 슬로건: **Build real conversations, block by block.**
- 한국어: **듣고, 말하고, 읽기 공부는 생략.**

## 2. 그대로 지킬 것 (EarToMouth에서 이어짐)

- 해석(뜻)은 **맞힌 다음에** 보여 줘요.
- 상황은 가게 주문보다 **옆자리 대화** 중심 (비행기, 이자카야, 온천, 바 등)
- **0원 운영**: 서버 비용 없이 시작. 음성은 브라우저 기능(무료). 도메인 값만.
- 휴대폰이 기준이에요 (아래 7절)

### 하지 않을 것 (사용자가 직접 거절)

- 듀오링고 같은 것: 위에 X + 진행 막대 + 아래 큰 "계속" 버튼, **단어 타일로 문장 조립**, 연속 기록(스트릭)·주간 체크, 길 따라 이어진 레슨 지도
- AI가 만든 것 같은 화면: 보라색 그라데이션, 이모지 카드, 반짝이(✦✨), em dash(—), 섹션 위 작은 머리말, "1·2·3 단계" 카드 묶음
- 스픽 같은 유료 구조
- 다른 서비스의 이름·캐릭터·그림·문장, 특정 완구 회사의 로고·상표 디자인

## 3. 브릭 컨셉

### 3-1. 구조물: 맞으면 일자로, 어긋나면 비뚤게, 틀리면 저 멀리

- 상대가 한 마디 하면 **민트 브릭**, 내가 대답하면 **코랄 브릭**
- **딱 맞으면 바로 위에 일자로** 딸깍 쌓여요 (엇갈려 쌓지 않아요)
- **어긋나면 반 칸쯤 비뚤게** 얹혀요. 그래도 쌓이고 대화는 이어져요
- **틀리면 저 멀리 튕겨 나가요** (화면 밖으로 빙글빙글 날아감)
- 대화 하나(3~5턴)를 마치면 맨 위에 **노란 완성 브릭**이 얹혀요

### 3-2. 상대 말 → 뜻 맞히기: 4지선다 + "여기엔 없어요"

1. 상대가 말해요. 다시 듣기·느리게 듣기.
   - 말풍선에 **한글 발음**을 써 줘요 (예: "이-네! 코꼬노 야끼또리, 타베따?"). 회사에서 이어폰 없이 화면만 볼 때도 할 수 있게요.
   - **일본어 글자는 작고 흐리게** 함께 보여 줘요 (읽기 공부가 목적이 아니니까).
2. 아래에 **뜻이 적힌 브릭 4개**가 나와요. 그리고 **"여기엔 맞는 뜻이 없어요"** 버튼이 있어요.
   - 누르면 **다른 브릭 4개**가 나와요. 정답은 앞 4개에 있을 수도, 뒤 4개에 있을 수도 있어요 (찍어서 맞힐 확률이 1/4보다 낮아요).
   - 정답이 있는데 "없어요"를 누르면 버튼이 흔들리고 놓친 걸로 쳐요.
   - 뒤 4개에도 "여기에도 없어요" 버튼이 있어요. 뒤에서 앞으로 돌아갈 수도 있어요.
3. 맞는 브릭을 고르면 구조물 위로 날아가 **딸깍** 끼워져요.
4. 틀린 브릭은 부딪힌 뒤 **저 멀리 튕겨 나가요**. "오답" 글자는 쓰지 않아요.
   - 한 번 놓치면: 상대가 느리게 한 번 더 말해 줘요
   - 말풍선의 **힌트** 버튼: 누르면 힌트 단어(한글 발음 + 뜻)를 보여 줘요. **힌트를 쓰고 맞히면 브릭이 살짝 비뚤게** 쌓여요 (3-8절)
5. 맞히면 **꼭 들어야 할 단어**를 크게 보여 줘요(누르면 들려줌). 그다음 문장 발음(핵심 단어 강조)과 뜻.
   - 놓쳤던 대사의 단어에는 "놓친 단어" 표시 → 빠진 돌기로 남고 복습에 나와요

### 3-3. 내 대답: 딱 맞음 / 어긋남 / 틀림 (세 칸)

| 칸 | 기준 | 브릭 |
|---|---|---|
| **딱 맞음** | **핵심 단어가 들어 있음** (문장이 아니어도 됨) | 바로 위에 일자로 딸깍 |
| **어긋남** | 통하긴 하는데 핵심 단어가 빠졌거나 어색함 (외국인 티) | 반 칸쯤 비뚤게 얹힘 |
| **틀림** | 질문과 **상관없는 말** | 저 멀리 튕겨 나감 |

어긋남의 예 (사용자가 든 예):
- 단어 대신 가리키면서 **"이거!"** (핵심 단어가 빠짐)
- **때(시제)가 안 맞음**: "어땠어요?" → "맛있네", "먹어 봤어요?" → "먹어요"
- **숫자·날짜를 서툴게**: "언제 귀국해요?" → "일, 이, 삼 일", "셋일 뒤", "내일 내일 내일"
- **존댓말 질문에 반말**로 대답: "식사 어땠어요?" → "응, 맛있어" (강조하지 않고 가볍게)

질문별 예:

| 질문 | 딱 맞음 | 어긋남 | 틀림 |
|---|---|---|---|
| 뭐 마셔요? | 비-루! / 비-루데스 / 하이보-루 | (가리키며) 코레! (이거!) | 오이시-! (맛있어요) |
| 어느 나라 사람이에요? | 와따시와 칸코쿠진데스 / 칸코쿠진 / 칸코쿠 | | |
| 식사 어땠어요? | 아주 맛있었어요 | 응, 맛있어 | 날씨 좋네요 / 차가 막히네요 |
| 언제 귀국해요? | 3일 뒤 / 12월 10일 / 이번 주 금요일 | 3일을 틀린 읽기로, "일, 이, 삼 일", "내일 내일 내일" | 길이 막히네요 |

### 3-4. 말투

- 반말·존댓말은 **특수한 경우라 크게 강조하지 않아요.**
- 상대가 반말로 물으면 말풍선 옆에 작게 **"반말"** 표시만 해요.
- 반말 질문에는 반말로 답해도, 존댓말로 답해도 **딱 맞음**이에요.

### 3-5. 어긋났을 때 / 튕겼을 때

- **어긋남:** 비뚤게 얹힘 → "통하긴 했어요" → **"이 단어로 바꾸면 딱 맞아요"**(단어 크게 + 소리) → 다시 말해 딱 맞으면 비뚤어진 브릭이 스르륵 바로 서요. 그냥 넘어가도 돼요.
- **틀림:** 저 멀리 튕겨 나감 → 상대가 "응? 한 번 더?" → **"이 단어를 넣어 대답해 보세요"**(단어 크게 + 소리)
- **정말 쉬운 질문에서 틀렸을 때:** "일본어 잘 못해요", "천천히 말해 주세요" 같은 **살리는 말**도 추천해요 (대사마다 "쉬움" 표시)
  - 살리는 말을 실제로 하면: 브릭은 안 쌓이지만 튕기지도 않고, 상대가 더 천천히·쉽게 다시 물어봐요

### 3-6. 브릭 종류

| 브릭 | 색 | 뜻 |
|---|---|---|
| 상대 브릭 | 민트 `#29B6A5` | 상대가 한 말 (알아들으면 생김) |
| 대답 브릭 | 대답한 **단계 색** (4절) | 내가 한 대답. 1단계 말하기 = 반짝이는 코랄 `#FF7967`, 2단계 쓰기 = 반짝이는 하늘 `#5AB0E6`, 3단계 고르기 = 수수한 돌색 `#C3BCAE`. 구조물만 봐도 "이번엔 말로 많이 대답했네"가 보여요 |
| 질문 브릭 | 노랑 `#FFC857` | 내가 되물은 말. 옆으로 돌기가 하나 더 나와 있어요 (asmrBlock 블록의 오른쪽 돌기 오마주) |
| 완성 브릭 | 노랑 | 대화 하나를 마치면 맨 위에 |
| 빠진 돌기 | (브릭에 구멍) | **놓친 단어**. 복습에서 맞히면 돌기가 채워져요 |
| 비뚤어진 브릭 | (기울어짐) | **어긋난 대답**. 다시 말하면 바로 서요 |

### 3-8. 힌트를 쓰면 비뚤게

- **뜻 맞히기와 내 차례 둘 다** 해당해요. 힌트를 보고 맞히면 딱 맞아도 **살짝 비뚤게** 쌓여요
- "툭. 힌트로 맞혔어요 · 다음엔 힌트 없이 해 봐요!"
- 처음 온 사람 안내에도 설명해요

### 3-7. 소리·느낌

- 맞음 **딸깍**, 어긋남 **툭**, 튕김 **퉁 + 휘익**. 소리 끄기 가능
- 안드로이드는 짧은 진동도 (아이폰 브라우저는 진동을 지원하지 않음)
- 폰의 "동작 줄이기"가 켜져 있으면 움직임 없이 결과만

## 4. 내 차례 화면: 말하기 → 쓰기 → 고르기

> "1·2·3단계"는 **만드는 사람끼리 쓰는 말**이에요. 화면에는 단계 이름·번호를 보여 주지 않아요 (사용자가 "1단계도, 2단계도 다 통과해야 하나?" 하고 느낄 수 있으니까). 버튼도 "써서 바로 세우기", "골라서 대답하기"처럼 하는 일로 써요.

난이도는 **1단계 = 2단계 >>> 3단계**. 그래서 1·2단계 브릭은 **반짝이는 예쁜 브릭**, 3단계 브릭은 **광택 없는 칙칙한 돌 브릭**이에요 (색은 나중에 다시 정할 수 있음).

| 단계 | 방법 | 브릭 |
|---|---|---|
| **1단계** | 눌러서 말하기 | 반짝이는 코랄 |
| **2단계** | 한글 발음으로 직접 쓰기 | 반짝이는 하늘 |
| **3단계** | 객관식 고르기 | 수수한 돌색 |

### 1단계: 말하기
- 버튼은 **"눌러서 말하기"** 와 **"지금은 말할 수 없어요"** 두 개만
- 딱 맞음 → 바로 위에 딸깍
- 어색함 → 비뚤게 쌓임 → [그냥 넘어가기] 또는 [**2단계에서 바로 세우기**]
- 어눌하거나 틀리거나 인식이 안 됨 → **"말이 인식이 안 되거나 틀렸어요"** → [다시 대답하기] 또는 [**텍스트로 대답하기 → 2단계**] (튕기지 않음: 잘못 알아들은 건지 틀린 건지 구분이 어려우니까)
- "지금은 말할 수 없어요" → 바로 **2단계**

### 힌트 (1·2단계)
- 1단계: "힌트 보기"를 누르면 추천 대답의 한글 발음이 나와요. 2단계: 힌트 단어가 나와요
- 힌트를 쓰고 딱 맞게 대답하면 → **비뚤게** 쌓여요 (3-8절)

### 어긋났을 때 이유와 해석
- "왜 비뚤어졌나요?"를 보여 줘요. 예: 타베마스 = "먹어요(지금·앞으로 할 일)". 타나카 씨는 "먹어 봤어요?"(지난 일)를 물었으니 "타베마시따(먹었어요)"로 말하면 딱 맞아요
- 들린 말/쓴 말/고른 말에도 뜻을 함께 보여 줘요

### 2단계: 쓰기
- 한글 발음으로 써요. 단어 하나만 써도 딱 맞음
- 글자로도 어렵다면 **"그래도 골라서 대답하기"** 버튼. 옆에 **반짝이는 코랄 브릭이 눈물을 흘리는 그림**과 "대신 반짝이는 브릭이 울어요. 칙칙한 돌 브릭이 쌓이거든요." (이모지 대신 그림으로)
- 딱 맞음 → 딸깍 (1단계에서 비뚤어진 브릭이 있었으면 스르륵 바로 섬)
- 애매함 → **"애매한 답변이에요"** → 비뚤게 쌓임 → [그냥 넘어가기] 또는 [**3단계에서 바로 세우기**]
- 상관없는 답 → **저 멀리 튕겨 나감** → [다시 쓰기] 또는 [**3단계로 갈래요**] + "말이 안 나오면" 살리는 말
- 살리는 말("스미마셍, 니홍고가 니가떼데")을 쓰면 → 상대가 쉽게 다시 물어봐요

### 3단계: 고르기
- 대답 브릭 **4개**, 브릭에는 **한글 발음만** (한국어 뜻은 보여 주지 않음)
- 4개 안에는 딱 맞음·어긋남·틀림이 섞여 있어요
- 새로고침 화살표 버튼 **"여기엔 맞는 대답이 없어요"** → 다른 4개 (딱 맞는 대답은 앞이나 뒤 한쪽에만)
- 누르면 앱이 대신 말해 주고 판정. 옆의 작은 버튼으로 먼저 들어 볼 수 있음
- 틀린 브릭 → 저 멀리 튕겨 나가고, **남은 보기에서 다시 고르기**
- 어색한 브릭 → 비뚤게 → [다시 골라서 세우기]

### 결과
- **단어 중심**: 들린 말/쓴 말/고른 말 → 통한 단어 / 바꿀 단어 / 넣을 단어를 크게 (여기서는 뜻도 보여 줘요)
- 3단계로 쌓았으면 "말하거나 써서 대답하면 반짝이는 브릭이 쌓여요"로 다음엔 1·2단계를 해 보게 해요

### 4-1. 마이크 음성 인식

- 브라우저에 들어 있는 음성 인식(Web Speech API)을 써요. 크롬(PC·안드로이드)과 아이폰 사파리에서 돼요. **우리 쪽 비용은 0원**, API 키도 필요 없어요.
  - 소리는 크롬은 구글, 사파리는 애플 서버로 가서 글자로 바뀌어요 → 개인정보 안내에 적어야 해요. 인터넷이 필요해요.
  - 파이어폭스, 카카오톡 같은 앱 안 브라우저 등 지원하지 않는 곳에서는 바로 브릭 고르기로
- 바뀐 글자(일본어)에 **핵심 단어가 들어 있는지** 규칙으로 판정해요 (9절). 후보 5개를 받아 하나라도 맞으면 인정
- 원어민 말은 꽤 잘 알아듣지만, 한국어 억양의 **짧은 단어 하나**("마다")는 잘못 알아들을 수 있어요 → 애매하면 튕기지 않고 **"말이 인식이 안 되거나 틀렸어요" → 다시 말하기 또는 2단계(쓰기)**
- 발음 점수를 매기는 유료 서비스(발음 평가)는 쓰지 않아요. 단어가 통하면 되니까
- 실제 휴대폰에서 아직 시험 못 해 봤어요. 마이크는 https 주소에서만 돼서, 미리보기(claude.ai)에서는 안 되고 배포한 뒤 시험해야 해요

## 4-2. 안내 팝업 두 가지

### 사이트에 처음 들어왔을 때 (6장)
- 한 번 떠요 (asmrBlock의 처음 사용법 팝업처럼). 건너뛰기 가능, 도움말에서 다시 보기
  1. **옆 사람과 스몰토크하려고 만들었어요** (카운터에 나란히 앉은 두 사람, 말풍선과 브릭)
  2. **목표는 적당한 스몰토크예요** (최종 목표는 현지인 같은 대화지만 먼저 갈 곳은 스몰토크. 탑이 "스몰토크" 선까지 쌓임)
  3. **오로지 대화에만 집중해요** (듣기 ⇄ 말하기가 화살표로 주고받고, 가운데 "쌓이는 대화 능력" 탑)
  4. **읽기 공부는 하지 않아요** ("Reading" 글자 위에 큰 X가 그어짐)
  5. **그럼 글자를 읽고 싶을 땐요? 메뉴판이나 안내문 같은 거요!** (손 드는 학생, 메뉴판)
  6. **그건 번역 앱에 맡기세요** (휴대폰으로 메뉴판을 찍어 번역, 옆에서 무관심한 표정의 브릭) + "시작하기"
- 다른 서비스 이름(파파고, GPT, Claude 등)은 화면에 쓰지 않고 "사진 번역 앱이나 AI"로 써요 (asmrBlock과 같은 규칙)

### 대화(게임)에 처음 들어갈 때 (3장)
  1. **브릭이 내 대답을 보여 줘요**: 말하기·쓰기 = 반짝, 고르기 = 칙칙, 힌트·어색함 = 비뚤
  2. **어려울수록 브릭이 얇아져요**: 얇은 브릭이 높이 쌓일수록 고수 (피라미드)
  3. **이렇게 해요**: 듣고 뜻 맞히기 → 말로 대답 (어려우면 글자로, 그래도 어려우면 골라서) + "대화 시작"

## 5. 홈: 내 여행 판

- 길 지도·잠금 해제 대신 **레고 바닥판 하나**. 이자카야·온천·신칸센 같은 **자리**가 있고, 대화를 마친 곳에는 그때 쌓은 구조물이 서 있어요
- 아무 곳이나 골라서 시작 (잠금 없음)
- 연속 기록(스트릭)·콤보는 하지 않아요

## 5-1. 내 탑과 순위

- **대화 하나를 끝낼 때마다 브릭 1개, 하루 최대 3개** 내 탑에 쌓여요. 하루에 3개보다 많이 하면 **난이도가 높은 대화 순서로 3개만** 쌓여요. 요일마다 브릭 색이 달라요(월 민트, 화 코랄, 수 노랑, 목 하늘, 금 보라, 토 초록, 일 분홍)
- 이 규칙은 **팝업으로 안내**해요: 내 탑의 "쌓이는 방법" 버튼 + 하루 4번째 대화를 끝냈을 때 ("오늘 끝낸 대화 4개 → 어려운 순서로 3개만 쌓여요" 그림)
- **레벨이 오를수록 브릭이 작아져요** (5-2절) → 아래는 큰 Lv1 브릭, 위로 갈수록 작은 브릭 → 탑이 **피라미드**가 돼요
- **쉬어도 탑은 그대로예요.** 연속 기록(스트릭)처럼 끊기거나 줄지 않아요
- **순위는 첫 버전부터** 넣어요. 순위는 **브릭 개수**로 매겨요 (어려운 대화로 브릭이 얇아져도 손해 보지 않게). "이번 주"(하루 최대 3개 × 7일 = 최대 21개, 월요일마다 새로) / "전체" 두 가지. 작은 피라미드를 나란히 세운 모양으로 보여 줘요. **얇은 브릭이 높이 쌓일수록 고수**
- 순위는 서버와 로그인이 필요해요 (7절)
- 아래 탭: 여행 판 · 고치기 · 바로 쓰기 · **내 탑**

## 5-2. 난이도(레벨)

- 지금 이자카야 대화는 너무 쉬워요. 같은 장소라도 술 이야기만 하지 않고, 개인 사정·개인 토크로 넘어가면서 어려워져요
- **레벨은 숫자만** 써요 (Lv1, Lv2, … 앞으로 계속 늘어남). 레벨마다 "첫 만남" 같은 장르 이름을 붙이지 않아요 (레벨이 많아지면 억지가 되니까)
- **대화 주제는 따로 태그**로 달아요 (예: #술·안주 #여행 #일 #가족 #연애 #고민). 어떤 주제든 어느 레벨에나 나올 수 있어요
- 레벨이 오르면 어려워지는 것: 말 속도, 문장 길이, 핵심 단어 수, 뜻 보기끼리 비슷한 정도, 힌트 수, 반말·줄임말 비율 (예: 이자카야 낮은 레벨 "뭐 마셔요" → 높은 레벨 "요즘 회사 일은 어때?")
- 올라가는 방법(확정): 쉬운 레벨을 **완벽하게** 쌓으면(반짝이는 브릭, 힌트·어긋남 없이) "다음 레벨 해 볼래요?" 제안 (강제 잠금은 아님) + **직접 레벨 고르기**도 가능
- **브릭 크기**: 레벨이 오를수록 조금씩 **얇고 작아져요** (일정 크기 아래로는 안 작아짐). 대화 구조물도 그 대화 레벨 크기로 쌓여요. **얇은 브릭이 높이 쌓일수록 고수**

## 6. 복습 = 구조물 고치기

- 놓친 단어(빠진 돌기)를 소리와 한글 발음으로 보고 뜻을 맞히면 돌기가 채워져요
- 간격 반복: 1일 → 3일 → 7일 → 14일 → 30일 (EarToMouth v5 그대로)
- 대화가 끝나면 "오늘 대화의 단어"를 모두 보여 주고, 놓친 단어를 표시해요
- 한국어와 소리가 닮은 단어(有名 유-메- ≈ 유명)도 가끔 추천

## 7. 플랫폼

- **사업으로 키울 생각**이에요. 그래서 asmrBlock처럼 **로그인·메뉴·도메인**을 갖춰요
- 순서: **웹(앱처럼 쓰는 PWA) → 인기가 있으면 앱 출시**. 앱 출시 비용(구글 플레이 등록 1회 25달러, 애플 연 99달러)은 반응을 보고 결정
  - 모든 화면은 휴대폰 크기가 기준 (아이폰 SE 320px까지 넘치지 않게)
  - 홈 화면에 추가하면 앱처럼 (PWA)
  - 나중에 앱(asmrBlock처럼 Expo/React Native)으로 옮기기 쉽게: 판정·콘텐츠·복습 같은 로직은 화면과 분리
- 메뉴: 휴대폰은 아래 탭(여행 판 · 고치기 · 바로 쓰기 · 내 탑) + 오른쪽 위 내 정보·도움말, PC 웹은 위쪽 메뉴
- 로그인: 처음 온 사람은 가입 없이 바로 체험 → 기록 저장·순위 참여는 가입/로그인
- **도메인: oracyblock.com** (사용자가 2026-11-19에 구매)
- **서버: ① 집 PC + Cloudflare Tunnel** (asmrBlock과 같은 방식, 사용자에게 익숙함). 나중에 클라우드로 옮길 수 있게 처음부터 Docker로 묶어요 (asmrBlock처럼 `docker compose`)
- **서버 기술: asmrBlock과 같음** (Spring Boot + PostgreSQL + MyBatis, 웹은 React). 로그인 방식도 asmrBlock을 참고
  - 사용자는 "1개월·1년 무료 체험"보다 차라리 돈을 내는 쪽을 선호
- 시안의 "브릭 모양 비교"판은 **시안 전용**이에요. 실제 사이트·관리자 화면에는 없어요
- 언어: 한국어 화면 + 일본어 학습부터. 영어·중국어는 나중에 언어 팩으로

## 8. asmrBlock 오마주

- **같은 핏줄:** 브릭 만드는 법(진한 테두리·아래 두께·돌기), 블록 모양 버튼, 레고 판 카드, 제목 도현체, "AI 티 안 나게" 규칙
- **브릭 모양은 B(테두리)로 확정** (사용자가 시안 A·B·C 중 고름)
- **반대 분위기:** asmrBlock = 밤(잠)·옆으로 누운 블록·왼쪽→오른쪽 타임라인 / OracyBlock = 낮(여행)·크림 바탕·위로 쌓는 입체 블록

## 9. 대답 판정 (말하기·글자 모두)

### 기본: 규칙 판정 (0원)

- 대사마다 **딱 맞음 단어 / 어긋남 단어 / 살리는 말**을 미리 적어 둬요. 들어 있는 단어로 세 칸을 나눠요.
- 한글 발음은 사람마다 다르게 쓰니까, 비교하기 전에 **같은 모양으로 맞춰요**:
  - 된소리·거센소리 묶기 (ㄱ·ㄲ·ㅋ / ㄷ·ㄸ·ㅌ / ㅂ·ㅃ·ㅍ / ㅈ·ㅉ·ㅊ / ㅅ·ㅆ)
  - 받침 ㄴ·ㅇ·ㅁ → ん 하나로, 촉음 받침(ㅅ·ㄱ 등)은 빼기, 장음 표시 "-" 빼기
  - 예: 칸코쿠진 = 캉꼬꾸진, 타베따 = 타벳따 = 다베타
- 마이크로 말하면 음성 인식이 일본어 글자로 줘요 → 같은 방식으로 맞춰서 비교 (가나 ↔ 한글 발음 변환 표 필요)
- 한계: 미리 적어 두지 않은 대답(예: "뭐 마셔요?"에 "와인")은 모를 수 있어요 → 음료·나라·음식·숫자처럼 **자주 나오는 단어 묶음**을 만들어 넓혀요

### 나중에 선택: AI 판정

- 규칙으로 모르는 대답만 AI에게 물어보는 방식 (asmrBlock "오늘 밤 조합"처럼 키를 넣으면 켜지고, 없으면 규칙만)
- 모델: Claude Haiku 5.5 (입력 100만 토큰당 $0.10, 출력 100만 토큰당 $0.50)
- 한 번 판정 ≈ 입력 600 + 출력 150 토큰 ≈ $0.00014 ≈ **약 0.2원**
  - 1명이 하루 30번 → 하루 약 6원
  - 매일 쓰는 사람 100명 → 한 달 약 1.8만 원 / 1,000명 → 약 18만 원 (모든 대답을 AI로 보낼 때. 규칙이 먼저 거르면 훨씬 적음)
- API 키는 브라우저에 둘 수 없어서 아주 작은 서버가 필요해요 → Cloudflare Workers 무료 플랜(하루 10만 요청)으로 0원 가능
- 하루 사용 횟수 제한 + 실패하면 규칙으로 (asmrBlock과 같은 안전장치)

## 10. 아직 정하지 않은 것

- 레벨 숫자별 구체 기준 (말 속도·문장 길이·핵심 단어 수 등)과 "완벽하게"의 정확한 기준 (몇 개 대화를 연속으로?)
- 웹 첫 화면(PC) 시안 피드백
- 단계 색 (지금은 코랄·하늘·돌색, 나중에 다시 정함)
- AI 판정을 언제 붙일지 (지금은 규칙만)
- 한글 발음 표기: 긴 소리를 "오이시-"처럼 "-"로 쓸지, "오이시"처럼 뺄지
- 다크 모드
- 숫자를 틀리게 읽은 것(예: 3일)을 음성 인식으로 구분할 수 있는지 → 만들 때 실제로 시험
