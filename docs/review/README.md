# 일본인 검수 (concept 11-8)

- `talks-review.csv`: 모든 대사 표 (상대 말 · 다른 말투 · 맞는 대답 · 상대 반응 · 일부러 넣은 어색한 대답)
- 만들기: `cd web && npm run export:review` (대사를 고친 뒤 다시 만들어요)
- 일본인 지인에게 엑셀이나 구글 시트로 열어 보내고, **확인(O/X)** 칸과 **고칠 말 / 메모** 칸만 채워 달라고 하면 돼요
- "어색한 대답 (일부러)"는 일부러 틀리게 넣은 대답이라, 진짜로 어색한지만 봐 주면 돼요
- 받은 내용으로 `web/src/content/talks.js`를 고치고 `npm run check`로 검사해요

## 무료 AI로 먼저 걸러 보기 (concept 11-29)

- `ai/part-01.txt` ~ `ai/part-11.txt`: 질문 + 대사 약 100줄씩. **파일 하나를 통째로 복사**해서 무료 AI 채팅(Gemini, ChatGPT 등)에 붙여 넣으면 돼요
- AI가 준 표(번호 · 문제 · 고칠 말 · 이유)를 그대로 Claude에게 붙여 주면, 하나씩 다시 확인한 다음 고쳐요 (AI도 틀릴 수 있어서 바로 반영하지 않아요)
- 두 AI 이상에게 같은 파일을 보내서, 둘 다 어색하다고 한 줄을 일본 사람에게 물어보면 가장 확실해요
- `npm run export:review` 할 때 같이 다시 만들어져요
