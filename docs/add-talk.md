# 대화 더하는 순서

새 장소 대화를 넣을 때 이 순서대로 해요. 2026-11-26 대화 8개(사슴 공원 … 새해 첫 참배 줄)를 넣으면서 정리했어요 (concept 11-59).

## 1. 시안부터

- 지금 장소와 겹치지 않는 후보를 시안으로 보여 주고 사용자가 고르게 해요 (CLAUDE.md "크게 바꾸기 전에는 시안")
- 후보마다: 레벨 · 상대 · 상황 한 줄 · 첫 대사 · 꼭 들어야 할 단어 · 내 대답 예

## 2. 대사 쓰기

| 파일 | 할 일 |
| --- | --- |
| `web/src/content/talks.js` | `TALKS` 끝(`];` 앞)에 더해요. 대화마다 10차례쯤, 상대 말마다 `alt`(같은 뜻 다른 말투) 하나, 대답 몇 개에 `react` |
| `web/src/content/build.js` | 레벨 표(`sakagura: 5,` 아래)에 `id: 레벨` |
| `web/src/components/Face.jsx` | `FACE_OF`에 `id: '얼굴'` (auntie, youngW, office, grandma, youngM, grandpa, master, driver, auntie2, host, youngW2, bob, office2, clerk, chef, auntie3, staff, student) |

- 한글 발음은 기존 표기를 따라요: 긴 소리 `-`, 말 중간 か·た행은 된소리, つ=쯔, ち=찌, っ는 받침, ん은 뒤 소리에 따라 ㄴ·ㅁ·ㅇ. 단어는 조사 앞에서도 제 모양 그대로 (캉코꾸데스, 지깡데스, 니혼와)
- 핵심 단어(`keys`·`words`)의 한글 발음은 그 줄의 한글 발음 안에 글자 그대로 들어 있어야 해요
- 대답 보기는 모두 "맞는 대답"이에요. `alt`의 뜻이 기본과 다르면, 대답들이 두 뜻 모두에 어울리게 써요

## 3. 검사하고 고치기

1. `cd web && npm run check` → `✗`는 꼭, `△`(한글 발음이 여러 가지)는 기존 표기에 맞춰 고쳐요
   - 같은 한자를 다른 뜻으로 읽는 줄(入れる↔入れない, 降る↔降りる)이 걸리면 그 줄은 가나로 써요
2. 음성이 한자를 바르게 읽는지: kuromoji 점검 스크립트로 새 줄만 보고, 잘못 읽는 말은 `web/src/lib/speech.js`의 `READ_AS`에 고정해요. 짧은 고정(一時·十分·方)이 긴 말(一時間·十分上手·そういう方)을 망가뜨리면 긴 말을 따로 더해요
3. 보기 확인: 새 대화의 뜻 보기·대답 보기를 뽑아 읽어 보고
   - 사실상 같은 뜻인 상대 말끼리 → `build.js`의 `ALSO_SIMILAR`에 한 묶음
   - 사실 맞는 대답인데 틀린 보기로 나온 것 → `NOT_WRONG`에 `'id:차례': ['뜻']`
4. `npm run check` 다시 → "문제 없음"
