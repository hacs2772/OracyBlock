## 1. 사용자가 원하는 것

### 한 줄
> 일본 여행에서 **옆자리 사람의 말을 알아듣고, 대답하는** 걸 연습하는 앱.
> 읽기·쓰기는 필요 없고 **듣기·말하기만** 해요.

### 사용자가 직접 한 말 (원문)
- "일본여행가서 현지인과 간단한 대화와 듣기 말하기만 하고싶어. 일본어를 읽거나 쓰는건 필요없단말이지."
- "듀오링고는 무료인데 쓸모없이 단어테스트랑 쓰기테스트도 보고, 스픽은 유료이고…"
- "웹이긴한데 대부분은 핸드폰으로 보니까!"
- "웹인데 앱으로도 볼 수 있고, ui는 너무 ai스럽지 않게!"
- "매일 연습을 해야하는데, 편의점 술집 음식점 등등도 맞는데 결국 일본은 **옆사람과 자주 대화**하잖아? 그런 대화를 알아듣고 말하는게 목표."
- "**문법이 완벽하지 않더라도 나는 말하는게 목표**이고, 완벽하진 않지만 **단어단어들을 캐치해 그사람이 무엇을 말하려는지 이해**하는 이 2가지가 가장 큰 목표이자 가치관."
- "이사람이 어떤걸 말하는지 정확히 캐치까진 할 필요없고 **특정단어와 어감** 같은게 중요하지. 특정 단어들만 알아도 무엇을 말하는지 알기에, 여러 단어들이 있다면 눌러서 끼워맞추는거지. 약간 오디오 드라마형이 비슷하긴하겠네. 그리고 내가 대답하려고 하는것도 고민해봐야지."
- "해석을 보는 느낌이 아니라 **맞추는 게임 형식**. 말을 들으면 여러 단어가 나와서 내가 선택할 수 있거나, 한번에 이사람이 무엇을 말하는지 **5지선다**가 있으면 그걸 누르거나. 그러면 이제 **내가 대답해야 할 것을 추천**하고."
- "물론 이사람이 무엇을 어떻게 말했는지 **해석도 최종적으로** 보여주긴 해야지."
- "**주요단어를 알려주고 복습하고 외우는 반복학습**."
- "**한국어랑 유사한 일본어 발음** 같은거 외우기 쉽잖아? 그런것도 가끔씩 추천해주고. 예를 들어 유명이 일본어로 유메잖아."
- "아무튼 **알아듣고 대답하는게 가장 큰 목표!**"

### 정리하면
1. **알아듣기:** 다 못 알아들어도 돼요. 들리는 핵심 단어와 말투(어감)로 뜻을 맞혀요. 해석을 보기 전에 **먼저 맞혀 보는 게임**이에요.
2. **대답하기:** 문법이 틀려도 핵심 단어만 말하면 통해요. 앱이 **무엇을 대답하면 좋을지 추천**해 줘요.
3. **외우기:** 들은 핵심 단어를 간격을 늘려 가며 반복 복습해요. 한국어와 소리가 닮은 단어도 가끔 추천해요.
4. **상황:** 가게 주문보다 **옆자리 사람과의 대화**가 중심이에요(비행기, 이자카야, 온천, 바 등).
5. **매일** 조금씩 해요.
6. **비용:** 무료로 운영할 수 있어야 해요. 도메인 비용 정도만 괜찮아요. 서버 비용이 들지 않게 해 주세요.
7. **기기:** 휴대폰으로 봐요. 웹이지만 홈 화면에 추가하면 앱처럼 써요(PWA).

## 2. 하면 안 되는 것 (사용자가 직접 거절한 것)

### 듀오링고처럼 보이는 것
사용자가 두 번이나 "너무 듀오링고 같다, 당장 바꿔야 한다"고 했어요. 직접 짚은 부분은 이래요.
- **레슨 화면 구조:** 위에 X 버튼과 진행 막대, 아래에 큰 "계속" 버튼, 보기 고르기를 반복하는 화면
- **단어 타일·블록:** 단어 조각을 눌러 문장을 조립하는 방식
- **연속 기록(스트릭)과 주간 체크**
- **이어진 경로 목록:** 레슨이 길 따라 이어진 지도나 목록

### "블록"이라는 이름에 대한 주의
- OracyBlock의 "블록"은 asmrBlock의 오마주예요. asmrBlock에서는 짧은 블록을 쌓아 조합하는 개념이에요.
- 하지만 사용자는 **듀오링고식 단어 타일·블록을 거절했어요.**
- 블록이 무엇을 뜻하는지 사용자에게 꼭 확인하세요. 문장 조립용 단어 타일처럼 보이지 않게 해야 해요.

### 그 밖에 거절한 것
- **AI가 만든 것 같은 UI.** 흔한 보라색 그라데이션, 이모지 카드, 둥근 카드만 늘어놓은 화면 같은 것이에요.
- **해석을 그냥 보여 주는 흐름.** v4가 이렇게 지적받았어요. 해석은 반드시 **맞힌 다음에** 보여 줘요.
- **스픽처럼 유료 구조.**

### 저작권
- 듀오링고, 스픽, 기존 게임의 이름·캐릭터·그림·문장을 쓰지 마세요.
- 대사는 모두 새로 써 왔어요.

## 3. asmrBlock (오마주 대상)

- 저장소: `hacs2772/asmr_block`
  - 새 채팅에서 볼 때는 `add_repo` 도구로 붙여서 읽으세요.
- 소개 문구: "나만의 ASMR을 블록처럼 조합하세요."
- 3~4분짜리 **짧은 ASMR 사운드 블록**을 골라, 블록을 **쌓듯이 이어 붙여** 나만의 플레이리스트를 만들어요.
- 블록은 **카테고리 색으로 구분**돼서 구성이 한눈에 보여요.
  ```
  [빗소리][빗소리][키보드][속삭임][빗소리]
    🟢      🟢      🔵      🟣      🟢
  ```
  - 카테고리 색: 자연 #22C55E, 사물 #3B82F6, 신체 #A855F7, 음식 #F97316, 환경 #78716C
  - 브랜드 색: #6366F1, #EC4899
- 기술 스택: React 18 + Tailwind, Spring Boot + PostgreSQL. 다크 배경 #0f0f0f, Pretendard/Noto Sans KR 글꼴.
- 이 세션에서 본 클론은 기록이 한 커밋만 있는 얕은 복사본이었어요. 사용자가 말한 "웹인데 앱으로도 보는" 최신 모습은 저장소를 직접 확인하세요.
- **어떤 점을 오마주하는지는 사용자가 정해요.** 짐작해서 정하지 말고 사용자에게 물어보세요.

### v5의 흐름 (기능은 사용자가 요청한 그대로라 살릴 가치가 있어요)

#### 1. 상대가 말하면: 맞히기 게임
1. 소리가 나와요. 다시 듣기와 느리게 듣기가 있어요. 대사 글자는 보이지 않아요.
2. **들린 단어 고르기:** 9개쯤 되는 단어 구름에서 들린 단어를 눌러요.
   - 진짜 핵심 단어에 같은 앱의 다른 단어를 미끼로 섞어요.
   - 건너뛰고 바로 뜻을 고를 수도 있어요.
3. **5지선다:** "사토 씨가 뭐라고 했을까요?"
   - 정답 1개에, 같은 에피소드의 다른 대사 2개와 다른 에피소드 대사를 섞어 5개를 만들어요.
   - 고른 단어의 뜻을 힌트로 보여 줘요.
4. **결과:** "알아들었어요!" 또는 "아깝다! 정답은 X였어요"
5. **최종 해석:** 한글 발음(핵심 단어 강조), 뜻, 말투 설명을 보여 줘요.
   - 단어는 맞힌 것 / 놓친 것 / 잘못 고른 것으로 나눠 보여 줘요.
6. 닮은 단어가 있으면 팁을 보여 주고, "추천 대답 보기"로 넘어가요.

#### 2. 내 차례: 추천 대답
- 상황에 맞는 대답 1~2개를 보여 줘요.
  - 하고 싶은 말(한국어)
  - 자연스러운 문장(한글 발음)과 뜻
  - 핵심 단어
- 대답하는 방법은 세 가지예요.
  - 마이크로 말하기: 핵심 단어가 하나만 들려도 그 대답을 고른 걸로 봐요.
  - "소리 내서 말했어요" 버튼
  - "대신 들려주기"
- 못 알아들으면 상대가 되물어요("응? 한 번 더?"). 두 번 실패하면 "대신 들려주기"를 권해요.

#### 3. 에피소드 끝
- 알아들은 말, 통한 대답, 들은 단어 수를 보여 줘요.
- "오늘의 단어"를 보여 주고 복습 목록에 넣어요. 놓친 단어는 바로 복습할 수 있게 넣어요.

#### 4. 단어 복습 (간격 반복)
- 소리를 듣고 뜻 4개 중 하나를 골라요.
- 맞히면 다음 복습까지 간격이 늘어나요: 1일 → 3일 → 7일 → 14일 → 30일.
- 틀리면 처음부터 다시 하고, 이번 복습 안에서도 한 번 더 나와요.

#### 5. 한국어랑 닮은 단어
- 48개예요. 예: 有名 유-메- ≈ 유명, 約束 약소꾸 ≈ 약속, 家族 카조꾸 ≈ 가족, 無理 무리 ≈ 무리
- 홈에 "오늘의 닮은 단어"가 매일 바뀌어 나오고, 복습 목록에 넣을 수 있어요.
- 소리가 덜 닮은 것(旅行 료꼬-/여행, 最高 사이꼬-/최고, 学生 가꾸세-/학생)은 뺐어요.

#### 6. 그 밖의 화면
- **바로 쓰기:** 10개 상황 표현집. 검색과 크게 보여 주기가 있어요.
- **단어 노트**
- **설정:** 말하기 속도, 음성, 마이크 테스트, 마이크 끄기, 일본어 글자 보기, 효과음, 테마, 기록 초기화

## 5. 그대로 가져가면 좋은 것

### 콘텐츠 (`js/talks.js`, `js/content.js`)
대사는 모두 이 앱을 위해 새로 썼고, 일본어 원어민 검수는 아직 안 했어요.

- **에피소드 10개** (`TALKS`): plane(비행기 옆자리, 존댓말), guesthouse, izakaya, onsen, shinkansen, park, bar(존댓말), taxi(존댓말), festival, farewell
- 대사 형식:
  ```js
  { them: { ja: '旅行ですか？', ko: '료꼬-데스까?', mean: '여행이에요?', keys: [['りょこう|旅行', '료꼬-', '여행']] } }
  { me: [ { intent: '여행이라고 하기', words: [['りょこう|旅行','료꼬-','여행']],
            natural: ['はい、旅行です', '하이, 료꼬-데스', '네, 여행이에요'],
            react: { ja, ko, mean } /* 선택 */ } ] }
  ```
  - 단어 형식은 `['かな|漢字', '한글 발음', '뜻']`이에요.
  - 첫 표기로 소리를 내고, 모든 표기를 음성 인식 정답으로 봐요.
  - 핵심 단어의 한글 발음은 문장의 한글 발음 안에 그대로 들어 있어야 해요. 강조 표시를 그 위치에 하기 때문이에요.
- `WORD_GROUPS`: 질문 단어, 맞장구, 만능 단어
- `ASK_AGAIN.casual / .polite`: 되묻는 말
- `COGNATES`: 닮은 단어 48개, `['ゆうめい|有名', '유-메-', '유명']` 형식
- `toneOf(line)`: 문장 끝(の？, か？, でしょ, ね, よ, ！)을 보고 말투 설명을 만들어요.
- `js/content.js`의 `UNITS`: 편의점·식당 등 10개 상황 표현집. 지금은 "바로 쓰기" 화면에서만 써요.

### 음성 (`js/speech.js`)
모두 브라우저 기능이라 무료예요.

- **읽어 주기 (speechSynthesis)**
  - 일본어 음성을 고르는 우선순위가 있어요.
  - **iOS에서는 첫 터치 때 빈 문장을 한 번 말해서** 음성 재생을 풀어 줘야 해요(`unlock()`).
- **음성 인식 (webkitSpeechRecognition)**
  - `ja-JP`, 후보 5개(`maxAlternatives 5`)
  - 마이크는 HTTPS에서만 동작해요. 크롬과 사파리에서 돼요.
- **`normalizeJa`:** 비교하기 전에 글자를 같은 형태로 맞춰요.
  - NFKC 정규화
  - 가타카나 → 히라가나
  - 한자 숫자 → 아라비아 숫자
  - 문장부호와 장음 기호(ー) 제거
- **`similarity`:** 레벤슈타인 거리로 비슷한 정도를 재요.
- **`matchIntent(alternatives, options)`:** 들린 말에서 핵심 단어가 가장 많은 대답을 골라요.
  - 핵심 단어가 하나도 없으면 자연스러운 문장과 비교해 비슷한 정도가 0.6 이상일 때 인정해요.
- `window.EARTOMOUTH_NO_MIC = true`로 음성 인식을 끌 수 있어요. 미리보기용이에요. 이름은 바꿔도 돼요.

### 복습 (`js/store.js`)
- localStorage 키는 `eartomouth-v3`예요. 새 앱에서는 새 키를 쓰세요.

## 6. 기술 메모와 겪은 문제

- **현재 구조:** 빌드 없는 순수 HTML/CSS/JS ES 모듈 PWA
  - `manifest.webmanifest`
  - `sw.js`: 바뀐 내용을 반영하려면 `VERSION`을 올려야 해요. 구글 폰트도 캐시해요.
  - 아이콘: 192, 512, maskable, apple-touch
  - 새로 만들 때 React 같은 도구를 써도 되지만, 무료 정적 호스팅에 올릴 수 있게 해 주세요.
- **배포 계획:** Cloudflare Pages(무료) + 사용자가 살 도메인
  - 사용자는 도메인을 OracyBlock에 맞춰 살 예정이에요.
  - 저장소 이름은 사용자가 GitHub에서 직접 바꿔요.
- **휴대폰 화면에서 주의할 점**
  - 320px 폭에서 그리드 항목이 넘치면 `grid-template-columns: minmax(0, 1fr)`로 해결돼요.
  - 버튼 배경색에 `transition`을 걸면 상태가 바뀔 때 색이 번쩍여요. 빼 주세요.
  - 5지선다 보기 5개가 iPhone SE(320×568)에서 스크롤 없이 보여야 해요. 맞히는 단계에서는 파형을 작게 줄였어요.
  - 이름이 겹친 클래스(`.st`, `.sw`) 때문에 다른 화면의 스타일이 섞인 적이 있어요. 클래스 이름은 겹치지 않게 지어 주세요.
- **claude.ai 미리보기(Artifact)의 제약**
  - `#/경로` 형식 주소가 안 돼요. `#home`, `#ep-plane`처럼 `#이름` 형식으로 썼어요.
  - 서비스 워커와 마이크가 안 돼요.
  - 그래서 모든 모듈을 파일 하나로 묶어 올렸어요. 스크립트는 `tools/build_preview.py`예요.
    - 실행: `python3 tools/build_preview.py . out.html`
    - 각 모듈을 함수로 감싸고, CSS와 아이콘을 안에 넣어요.
    - 모듈 순서는 `ORDER` 목록에서 정해요.
- **테스트 방법:** Playwright, iPhone 13 크기
  - 에피소드 하나를 끝까지 진행 → 복습 → 다크 모드 → 320px에서 가로 넘침 확인 순서로 돌렸어요.
- **아직 확인 못 한 것**
  - 실제 휴대폰에서 마이크 음성 인식
  - 원어민의 대사·한글 발음 검수
